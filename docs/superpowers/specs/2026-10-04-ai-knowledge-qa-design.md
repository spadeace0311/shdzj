# 上海地震应急 AI 知识与问答子系统设计规格

日期：2026-10-04
状态：需求设计已确认，待用户审阅
当前阶段：设计规格，不进入编码、脚手架或部署实施

## 1. 建设目标

为上海市地震应急评估与辅助决策平台增加面向震后处置场景的 AI 知识问答能力。系统需要帮助局领导和管理者快速获得以下问题的可信答案：

- 震中距离最近断裂带多少公里。
- 震中一定范围内发生过哪些历史地震，最大震级是多少。
- 当前震中与指定历史地震相距多少公里。
- 预测烈度、受灾人口、房屋破坏、人员伤亡和经济损失是多少。
- 当前事件已有哪一版专业图件、报告和工作组成果。
- 某项结论依据哪份预案、制度、论文、数据版本或评估结果。

首期只支持文字提问，回答可以包含文字、表格、引用证据和地图联动。AI 不替代制度响应、领导决策、正式外报和值班人员判断。

## 2. 范围边界

### 2.1 首期范围

- 接入 DeepSeek 在线模型进行意图理解、工具选择和回答组织。
- 使用本地 `BGE-M3` 生成中英文稠密与稀疏向量。
- 使用 `Qdrant` 保存知识库向量和稀疏检索索引。
- 使用 `BGE-reranker-v2-m3` 对混合检索结果重排。
- 支持本局预案、制度、历史报告、图件说明、公开规范、论文和技术资料入库。
- 支持管理员上传文件、粘贴 URL 和从白名单网站抓取资料。
- 支持事件、断层、历史地震、行政区、人口、建筑、烈度、损失和成果查询工具。
- 支持独立“智能问策”页面，以及事件详情页和指挥大厅内的上下文问答面板。
- 支持文字回答、引用证据、工具执行过程和受控地图动作。
- 支持外网联网知识更新模式，以及无联网的内网检索模式。
- 保存问答审计、模型版本、知识快照、工具参数、工具结果和回答版本。

### 2.2 明确不在首期范围

- 不支持图片、音频和视频提问。
- 不开发手机端。
- 不允许模型自行生成 SQL、PostGIS 表达式、坐标、距离、统计值或地图脚本。
- 不允许模型直接执行任意 URL、下载附件或改变数据资产。
- 不自动发布正式报告、不自动启动制度响应、不自动发送外部通知。
- 不对扫描件执行 OCR 自动解析；无法提取文字的文档明确标记失败。
- 不依赖商业搜索 API。搜索供应商、白名单抓取和人工录入通过适配器隔离。
- 不实现完整多租户；数据模型保留独立部署和多知识库扩展边界。
- 不提供模型隐藏思维链。仅保存问题、结构化计划、工具调用和最终回答。

## 3. 已确认的关键决策

- 大模型供应商为 DeepSeek。
- DeepSeek 使用 OpenAI-compatible 接口，默认模型为 `deepseek-flash`，模型名称可通过配置替换。
- DeepSeek 当前 API 不提供通用文本嵌入接口，不用于向量化。
- 嵌入模型为本地 `BGE-M3`。
- 向量和稀疏检索存储为独立 `Qdrant` 容器。
- 重排模型为本地 `BGE-reranker-v2-m3`。
- 所有数值、坐标、距离、排名、筛选和空间关系必须来自确定性后端工具。
- 知识库分为本局资料、结构化实时数据和公开资料三层。
- 外网阶段允许从白名单来源更新知识库，内网阶段完全关闭联网抓取。
- 首期搜索入口为白名单抓取、管理员上传文件和粘贴 URL，不绑定商业搜索 API。
- 问答入口包括独立页面、事件详情内嵌面板和指挥大厅内嵌面板。
- 事件问答锁定事件知识快照，后续知识更新不改变历史证据链。
- 地图只执行后端预定义并校验的动作。

## 4. 总体架构

### 4.1 后端模块

新增 `app.knowledge`：

- 知识来源、文档版本、网页快照、解析结果和访问级别。
- 文档切片、向量状态、索引版本和知识快照。
- 上传、抓取、解析、切片、嵌入、发布、停用、回滚和重建任务。
- 引用证据的稳定标识和来源追溯。

新增 `app.qa`：

- 问答会话和事件上下文。
- 问题、结构化执行计划、检索命中和工具调用。
- DeepSeek 模型调用、回答版本、引用证据和地图动作。
- 用户反馈、审计记录和运行指标。

复用现有业务服务：

- 事件、正式报修订和响应建议。
- 烈度、融合烈度和损失评估。
- 数据资产、行政区、断层、历史地震和空间查询。
- 自动成果、发布版本和人工修订成果。
- 用户、角色、事件授权和超级管理员权限。

### 4.2 独立进程

新增 `knowledge-worker`：

- 消费知识入库任务。
- 解析、切片、调用本地嵌入服务并写入 Qdrant。
- 执行白名单网页抓取和内容校验。
- 发布或回滚知识索引版本。
- 记录失败原因并支持安全重试。

问答请求在 API 内完成，但模型和嵌入服务通过适配器隔离：

- `DeepSeekAdapter` 负责在线模型调用和流式响应。
- `EmbeddingAdapter` 负责 BGE-M3 稠密与稀疏向量。
- `RerankerAdapter` 负责候选证据重排。
- `WebSearchAdapter` 负责白名单抓取；首期不绑定商业搜索 API。
- `MapActionBuilder` 只生成经过白名单校验的地图动作。

### 4.3 存储边界

PostgreSQL 保存：

- 知识来源、文档版本、切片元数据、索引版本和知识快照。
- 问答会话、问题、回答、引用、工具执行、地图动作和反馈。
- 入库任务、抓取快照、错误信息和审计记录。

Qdrant 保存：

- BGE-M3 稠密向量。
- BGE-M3 稀疏向量。
- 文档、版本、访问级别、来源类型、事件关联和时间元数据。

对象存储保存：

- 原始文件。
- 标准化解析文本。
- 网页正文快照。
- 必要的图片和表格提取产物。

PostgreSQL 是业务元数据和审计主数据源，Qdrant 是可重建检索索引。索引丢失时可以从 PostgreSQL 和对象存储重建。

## 5. 知识来源与治理

### 5.1 知识来源类型

首期支持以下来源：

- 本局预案、制度、流程和值班规范。
- 历史评估报告、专题图说明和复盘材料。
- 国家、行业和地方标准。
- 公开论文、技术报告和震害调查资料。
- 平台事件、评估和成果的结构化引用。
- 上海行政区划、断层、历史地震、人口和建筑数据。

### 5.2 来源分层

知识源分为三层：

1. `local_authority`：本局制度、预案、历史成果和授权资料。
2. `structured_live`：事件、评估、成果和基础数据的实时查询结果。
3. `public_reference`：公开规范、论文和技术资料。

实时数字优先使用 `structured_live` 工具查询。文档检索不能覆盖实时事件快照中的权威值。

### 5.3 文件与网页格式

文件首期支持：

- `DOCX`
- 文本型 `PDF`
- `MD`
- `TXT`
- `HTML`
- `XLSX` 和 `CSV` 的文本与表格内容

网页首期支持：

- 管理员粘贴的单个 URL。
- 白名单域名内的指定页面。
- 白名单来源的定时抓取。

扫描型 PDF、纯图片文档和无法可靠提取文字的格式不进入正式索引，入库任务状态为 `failed`，并提供明确错误说明。

### 5.4 文档生命周期

知识源版本状态为：

- `registered`
- `uploaded`
- `parsing`
- `parsed`
- `embedding`
- `indexed`
- `published`
- `failed`
- `disabled`

只有 `published` 版本可以参与正式问答。更新生成新版本，不覆盖旧版本。回滚只改变当前发布指针，不删除历史版本。

### 5.5 白名单与联网边界

外网知识更新遵循：

- 只访问配置中的域名白名单。
- 禁止访问本机、内网、云元数据地址和重定向到非白名单域名的 URL。
- 保存原始 URL、抓取时间、HTTP 状态、正文快照和内容校验和。
- 单个来源失败不能阻塞其他来源。
- 抓取内容进入候选版本，经解析和质量检查后才能发布。

内网部署配置为 `online_search_enabled=false`：

- 不发起任何外部网络请求。
- 不检查远程更新。
- 只使用本地已发布知识快照。
- 仍支持管理员导入离线文件和离线更新包。

## 6. 解析、切片与索引

### 6.1 解析

解析过程保留：

- 文档标题、来源、作者、发布机构和发布时间。
- 页码、章节标题、段落序号和表格位置。
- 原始文件位置和内容校验和。
- 访问级别、事件关联和有效期。

表格解析优先保留行列结构。无法可靠识别的表格不得拼接成含义不明的纯文本，应保留表格原文并标记解析限制。

### 6.2 切片

切片策略按文档结构执行，不按固定字符数机械切断：

- 标题和所属章节进入每个切片元数据。
- 中文正文目标长度为 500 至 1000 字。
- 相邻正文切片保留约 100 字重叠。
- 表格按表头、行组和完整语义边界切片。
- 页码和章节路径必须可回溯到原文。

### 6.3 向量与混合检索

每个正式切片生成：

- BGE-M3 稠密向量。
- BGE-M3 稀疏向量。
- 关键词索引字段。
- 文档、版本、来源类型、访问级别和时间元数据。

检索流程：

1. 根据用户和当前事件设置权限过滤。
2. 并行执行稠密向量、稀疏向量和关键词召回。
3. 按知识源、版本、事件和时间进行元数据过滤。
4. 使用 `BGE-reranker-v2-m3` 重排。
5. 按证据多样性去重，保留来源、页码和校验和。
6. 将有限数量的候选证据交给 DeepSeek 组织回答。

### 6.4 知识快照

事件问答创建时锁定：

- 当前事件和正式报修订。
- 评估运行和产品版本。
- 专业成果发布版本。
- 已发布知识索引版本。
- 基础数据和模型参数版本。

后续知识更新生成新快照。历史问答继续引用原快照，保证结果可复现。

## 7. 工具编排

### 7.1 执行计划

DeepSeek 首先输出受约束的 JSON 计划，包含：

- 问题意图。
- 需要调用的工具列表。
- 工具参数。
- 是否需要知识检索。
- 是否需要地图动作。
- 是否需要澄清。

计划只能选择注册表中的工具。参数经过 JSON Schema 和后端业务校验，不执行模型生成的 SQL、代码或任意表达式。

### 7.2 首期工具

首期注册以下确定性工具：

- `event.get_context`：获取当前事件和正式报版本。
- `event.get_revision`：获取指定修订报文。
- `fault.nearest`：查询最近断裂带及距离。
- `seismicity.within_radius`：查询半径内历史地震。
- `seismicity.distance`：计算两个地震事件的距离。
- `region.lookup`：定位行政区、边界和所属关系。
- `exposure.population`：查询人口和建筑暴露。
- `intensity.get`：查询模型、仪器和融合烈度。
- `loss.get_metrics`：查询损失指标及产品状态。
- `artifact.search_published`：查询当前发布成果、图件和报告。

工具必须返回：

- 标准值和单位。
- 数据来源和版本。
- 计算参数。
- 有效范围。
- 可能的缺数或不适用状态。

### 7.3 工具调用规则

- 同一计划中的独立工具可以并行执行。
- 有依赖的工具严格按顺序执行。
- 单工具超时、失败或返回无数据时，不继续构造该结论。
- 数值型回答直接引用工具结果，不允许 DeepSeek 四舍五入后改变精度语义。
- 多工具结果冲突时，工具定义优先于文档内容；同等级结果冲突时明确展示差异。
- 工具调用和参数全部进入审计记录。

## 8. 回答生成与证据规则

### 8.1 回答结构

正式回答包含：

- 直接结论。
- 计算或筛选依据。
- 数据来源与版本。
- 引用证据。
- 不确定性、缺数或降级说明。
- 可选地图动作。

复杂回答可以使用表格，但所有数值必须来自工具或可验证的文档原文。

### 8.2 证据引用

每条引用至少包含：

- 来源标题。
- 文档或事件版本。
- 页码、章节或时间范围。
- 原始片段。
- URL 或对象存储标识。
- 内容校验和。

点击引用可以查看原文片段；结构化结果可以定位到对应事件、评估产品或地图对象。

### 8.3 无依据处理

以下情况必须回答“无法确认”并列出缺失项：

- 没有检索到证据。
- 工具返回未找到。
- 数据版本不适用于当前事件。
- 用户没有访问权限。
- 数据源之间无法消除的冲突。
- DeepSeek 或 Qdrant 不可用且无法完成要求的推理。

不得使用模型常识补造应急预案、政策规定、坐标、距离、统计值或事件事实。

### 8.4 提示注入防护

上传文档、网页和引用片段均视为不可信内容。文档中的命令、角色指令、密钥请求或工具调用要求不得覆盖系统规则。任何外部内容都不能直接触发工具、联网、文件访问或权限变更。

## 9. 模型适配与运行策略

### 9.1 DeepSeek

- 默认模型：`deepseek-flash`。
- 接口格式：OpenAI-compatible。
- 支持流式回答、JSON 输出和工具调用参数生成。
- 模型名称、地址、超时和并发通过环境变量配置。
- API 密钥只保存在后端环境，不进入前端、日志、问答记录或错误响应。

### 9.2 本地组件

- BGE-M3 和 BGE reranker 通过独立适配器调用。
- 模型权重只从已配置来源安装到本地缓存。
- Qdrant 使用独立容器和持久卷。
- 本地组件健康状态进入系统运行监控。

### 9.3 超时与重试

- DeepSeek 非流式调用采用有限次数指数退避。
- 流式回答中断时保留已生成内容和已完成工具结果，并标记回答为 `partial`。
- 嵌入或索引任务失败进入重试，超过阈值后转为 `failed`，等待管理员处理。
- 重试不得重复创建知识版本或正式回答版本。

## 10. API 边界

建议新增以下 API：

```text
POST   /api/v1/qa/sessions
GET    /api/v1/qa/sessions
GET    /api/v1/qa/sessions/{session_id}
POST   /api/v1/qa/sessions/{session_id}/questions
GET    /api/v1/qa/answers/{answer_id}
POST   /api/v1/qa/answers/{answer_id}/feedback

GET    /api/v1/knowledge/sources
POST   /api/v1/knowledge/sources
POST   /api/v1/knowledge/sources/{source_id}/versions
GET    /api/v1/knowledge/versions/{version_id}
POST   /api/v1/knowledge/versions/{version_id}/publish
POST   /api/v1/knowledge/versions/{version_id}/rollback
GET    /api/v1/knowledge/jobs
POST   /api/v1/knowledge/jobs/{job_id}/retry
```

问答问题接口使用带认证的流式响应。流中区分：

- `retrieval`
- `tool`
- `answer_delta`
- `answer_completed`
- `map_action`
- `error`

流式响应失联后，客户端通过回答 ID 重新获取最终状态。

## 11. 前端交互

### 11.1 独立智能问策页面

页面分为三栏：

- 左侧：会话、历史问题和新建问题。
- 中间：回答、工具执行过程和反馈。
- 右侧：引用证据、结构化结果和地图。

回答流式显示；在流结束前不把临时文本标记为最终结论。引用和地图动作仅在服务端校验完成后展示。

### 11.2 事件详情和指挥大厅

- 内嵌问答抽屉自动携带当前事件、修订、评估运行和成果版本。
- 用户可以在权限范围内切换事件。
- 指挥大厅问答面板与主动态势图共享地图动作。
- `7680x2430` 和 `1920x1080` 下均不能出现文本遮挡、面板溢出或地图覆盖问题。

### 11.3 地图动作协议

首期支持：

- `locate`
- `fit_bounds`
- `buffer`
- `highlight`
- `set_layers`

动作包含目标对象、来源工具、有效期和显示理由。前端只接受预定义字段和图层 ID，不接受任意脚本、HTML 或外部 URL。

## 12. 权限与审计

### 12.1 权限

- 用户只能查询授权事件和授权知识源。
- 管理员可以维护知识源、上传、发布、停用和回滚版本。
- 超级管理员可以彻底删除知识源版本、问答记录和索引，但操作仍进入现有超级管理员审计体系。
- 受限知识源不送入在线模型；可以返回经权限校验的原文片段和确定性工具结果。

### 12.2 审计

记录：

- 用户、会话、问题和时间。
- 当前事件及知识快照。
- 检索条件、候选证据和最终引用。
- 工具名称、参数、结果摘要和耗时。
- DeepSeek 模型、Prompt 版本和响应状态。
- 地图动作和前端确认结果。
- 降级、错误、重试和反馈。

不在日志中记录 API 密钥、访问令牌、连接串和受限文档全文。

## 13. 性能与可靠性

目标：

- 混合检索 `P95 <= 1 秒`。
- 确定性工具 `P95 <= 1.5 秒`。
- 在线模型首字节 `P95 <= 3 秒`。
- 完整回答 `P95 <= 10 秒`，复杂多工具问题允许返回分阶段结果。
- 在不少于 10 万文本切片的索引上验证检索性能。
- 知识入库异步执行，不阻塞事件评估和指挥大厅 API。

降级：

- Qdrant 不可用时使用 PostgreSQL 全文检索，并显示降级标识。
- DeepSeek 不可用时返回检索原文和工具结果，不生成总结性回答。
- BGE reranker 不可用时使用混合检索原始排序，并显示降级标识。
- 在线知识更新失败不影响已发布索引。

## 14. 测试与验收

### 14.1 单元测试

- 文档解析、切片、元数据和校验和。
- 稠密、稀疏和关键词召回。
- 工具参数校验与结果格式化。
- 地图动作白名单和字段校验。
- 回答引用、无依据和冲突处理。
- 权限过滤和提示注入防护。

### 14.2 集成测试

- PostgreSQL 与 Qdrant 索引一致性。
- BGE-M3 和 reranker 适配器。
- DeepSeek 流式、非流式、超时和失败重试。
- 知识版本发布、回滚和事件快照。
- 白名单抓取、重定向阻断和联网关闭模式。
- 事件、烈度、损失、成果和知识库联合检索。

### 14.3 端到端验收

- “震中距最近断裂带多少公里？”
- “震中 50 公里内历史最大地震是什么？”
- “本次震中与指定历史地震相距多少公里？”
- 人口、烈度、损失和专业成果统计问答。
- 多轮追问保持当前事件上下文。
- 地图自动定位、绘制缓冲区和高亮结果。
- 结论可追溯到来源和工具结果。
- 无证据、无权限、工具失败和模型不可用时正确降级。
- 扫描件、损坏文档、提示注入和伪造引用不能产生错误结论。
- 外网模式可更新知识库，内网模式不发起外部请求。
- `7680x2430` 和 `1920x1080` 下无遮挡和溢出。
